# Pingpong Game 

A mini browser game built to practice **JavaScript, HTML, and CSS** skills.  
Test your reflexes by clicking the falling balls before they hit the ground!

![uistyle](/ui.png)

## How to Play

1. Click the **Start** button to begin.  
2. Balls will start falling from the top of the screen.  
3. Click on the balls to **reduce their number** and **soften their color**.  
4. Make sure each ball's number reaches **zero** and its color **fades completely to white** **before it touches the ground**.  
5. Each ball has a **unique color and speed**, so stay alert!  
6. If any ball touches the ground before fading completely, the game is over.

## Features

- Interactive, click-based gameplay  
- Balls with **different colors and speeds**  
- Real-time **color fading** and **number countdown**  
- Perfect practice project for **JavaScript beginners**
